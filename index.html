    Trust model

    Authentication proves. Authorization decides.

    These responsibilities are related, but they happen at different boundaries.

    01
    ◎

    Authentication

    For remote Streamable HTTP servers, OAuth 2.1-style flows establish who the client or user is.

    • Authorization Code + PKCE
    • Bearer access token
    • Resource indicators / audience binding
    • Issuer, expiry, and signature validation
    ≠
    02
    ◇

    Authorization

    The MCP server and downstream systems decide whether that identity may perform the requested action.

    • Scopes and token claims
    • Tenant / resource ownership
    • Server policy and consent
    • Downstream ACLs and data permissions
    Protocol boundary: A tools/call payload names a tool and its arguments—it does not grant permission. The server must enforce policy before execution, and downstream systems must enforce their own controls.
